# iPhone Safari 실기기 테스트 체크리스트

배포된 HTTPS 주소(Cloudflare Pages)에서 진행하세요.

## 설치
- [ ] Safari로 접속 → 공유 → **홈 화면에 추가** → 아이콘(빨간 배경 렌즈)과 이름 "Travel Lens" 확인
- [ ] 홈 화면 아이콘으로 실행 시 주소창 없이 전체 화면(standalone)으로 열림
- [ ] 상단 노치/Dynamic Island, 하단 홈 인디케이터에 UI가 가려지지 않음 (safe-area)
- [ ] 라이트/다크 모드 전환 시 색상이 자연스럽게 바뀜 (설정 → 디스플레이)

## 설정
- [ ] 설정 → 접근 토큰 입력 → 저장 → **연결 테스트**에서 "연결 성공"
- [ ] 앱을 완전히 종료 후 다시 열어도 토큰·선호 설정 유지
- [ ] 알레르기에 "새우" 등 입력 후 메뉴판 스캔 시 해당 메뉴에 ⚠️ 경고 표시
- [ ] 통화 변경 → 환율 자동 채움, "환율 불러오기" 동작

## 촬영 흐름
- [ ] **촬영하기** → 후면 카메라가 바로 열림
- [ ] **앨범에서 선택** → 사진 보관함에서 선택 가능 (HEIC 사진 포함)
- [ ] 세로/가로로 찍은 사진 모두 결과 화면의 "원본 사진 보기"에서 올바른 방향 (EXIF 보정)
- [ ] 로딩 중 스켈레톤과 로딩 문구가 바뀌며 표시
- [ ] 🍽 일본 이자카야 메뉴판 / 영어·프랑스어 메뉴판
- [ ] 🍷 와인 앞면 라벨, 뒷면 라벨
- [ ] 🍶 사케 앞면 라벨, 뒷면 스펙 라벨 (정미율·일본주도가 있으면 표시, 없으면 비어 있음)
- [ ] ✨ 자동 모드로 세 종류 각각 올바르게 판별
- [ ] 흐리거나 잘린 사진 → "인식 불확실" 배지가 붙는지

## 결과 화면
- [ ] 메뉴 항목 오른쪽 동그라미 체크 → 하단 **직원에게 보여주기 (n)** 버튼 → 큰 글씨 현지어 화면, ✕로 닫기
- [ ] 와인/사케 `match_with_user`가 초록(잘 맞음)/노랑(보통)/빨강(안 맞을 수 있음)으로 표시
- [ ] 별점·메모 입력 후 뒤로 갔다 와도 유지

## 기록
- [ ] 기록 탭에 썸네일 + 요약 + 날짜 + 별점
- [ ] 필터: 🍶 사케 + ⭐ 4점 이상 → "맛있었던 사케 n개"
- [ ] 기록 삭제 (🗑)

## 오류·네트워크
- [ ] 비행기 모드에서 스캔 → "서버에 연결할 수 없습니다" + 다시 시도 버튼
- [ ] 비행기 모드에서 앱 실행 → 앱 화면과 과거 기록은 열림 (오프라인 캐시)
- [ ] 잘못된 토큰 → "접근 토큰이 올바르지 않습니다" + 설정 열기 버튼
- [ ] 해석 중 앱을 백그라운드로 보냈다 복귀 → 결과가 오거나 "중단됨 → 다시 시도" 표시
- [ ] 1분에 20회 넘게 요청 → 429 안내 문구

## 비용 감각
- [ ] Anthropic Console에서 스캔 1회당 비용 확인 (메뉴판이 가장 큼)
